# test2
目前为止的版本
页面（10 个新增/重构）
页面	说明
首页 index	轮播 Banner、热门推荐（展开/收起）、精选模型横滑、商家入驻引导
模型库 model-list	分类筛选栏、搜索、模型卡片网格
模型详情 model-detail	模型信息、3D 预览入口
商家店铺 store-front	封面 + 店铺信息 + 模型列表 + 联系商家 + 顶部返回按钮
消息中心 merchant-center	消息列表（系统通知、商家动态、客服消息）
我的 profile	头像/昵称/签名编辑、登录/游客模式、普通/商家双模式切换
登录 login	验证码/密码双 Tab、微信一键登录、隐私协议、倒计时
注册 register	账号注册
重置密码 reset-pwd	密码重置
收藏 favorites	我的收藏列表
套餐购买 pricing	套餐定价页
商家模型管理 merchant-models	商家查看自有模型
店铺设置 shop-settings	店铺信息编辑 + 固定返回栏 + 商品管理（上架/下架/添加/删除）
自定义组件（3 个）
组件	说明
model-card	模型卡片（缩略图、面数标签、收藏按钮、名称、描述、商家信息、分类标签）、等高布局
tab-bar	底部导航栏（主页/模型库/消息/我的）
top-bar	顶部栏
数据模块（3 个）
模块	说明
data/models.js	8 个内置 3D 模型（头盔、鸭子、相机、灯笼等）
data/merchants.js	4 个商家数据
data/banners.js	首页轮播图
核心业务功能
功能	说明
登录体系	手机验证码/密码登录 + 微信登录，token + phone 双重登录态判断
商家入驻	「我的」页点击入驻 → 页面切换为商家模式，用户名旁显示「商家」标签
商品管理	店铺设置页内可添加新模型（缩略图/名称/描述/链接/分类/标签）、上架/下架开关、删除
收藏系统	模型收藏/取消收藏，心形按钮切换，持久化存储
登录数据合并	登录时保留登录前修改的昵称/签名；未登录也保留 merchantId
